Analysis for IHC Overlap on dual channel (cox6c/tpi1) to investigate mitochondrial translation across chemotherapeutic conditions.

Scrips do the following:

1. Cell Segmentation and Counts on nuclear staining
2. Custom global thresholding to preserve biologic significance
3. Pixel intensity adjusted colocalization
4. Condition specific visualizations
5. Cellpose QC images
6. Mitochondrial signal normalization, cell count normalization, cell area normalization


preprint: Mitochondrial translation is a targetable dependency of chemo-refractory triple negative breast cancer
